Predictive Modeling of Ventricular Wall Stem Cell Fate

Jessica Nari Yoon

Project goal and data

  • The goal of this project is to test whether a compartment-specific predictive model can use the observed P7 state to reproduce later ventricular wall composition at P14 and P30.
  • The dataset is a merged, imaging-based lab dataset summarized across six compartments defined by wall location and rostrocaudal region.
  • The main inputs are:
    • P7 stem cell count (S)
    • P7 ependymal cell count (E)
    • P7 fate probabilities (p_sym_self, p_asym, and inferred p_EE)
    • later observed composition (pct_S_mean, pct_E_mean)
    • average apical area (avg_apical_area) as a geometry proxy
  • Because these data were generated within the lab, the final citation or acknowledgement format should be confirmed with my advisor before submission.

This project asks whether early compartment-specific measurements are enough to predict later ventricular wall composition. I use a lab-derived imaging dataset organized into six anatomical compartments and focus on whether the observed P7 state can explain later stem cell and ependymal cell fractions.

Model, assumptions, and validation

  • I model each compartment as a two-population system:
    • S(t) = stem cells
    • E(t) = ependymal cells
  • The number of dividing stem cells is modeled with a binomial distribution, and division outcomes are modeled with a multinomial distribution.
  • The model uses a daily time step, apical-area interpolation, Huber loss, regularization, and Monte Carlo simulation for uncertainty.
  • Key assumptions:
    • ependymal cells are treated as non-dividing
    • migration, cell death, and measurement error are not modeled explicitly
    • apical area is treated as a proxy for tissue geometry
  • Validation is based mainly on RMSE, MAE, predicted-versus-observed plots, residuals, and compartment-specific SC/EC trajectories.

I chose a probabilistic model because stem cell fate is variable and compartment-specific. The binomial step captures whether a stem cell divides, and the multinomial step captures which fate that division takes. I keep the assumptions simple so the model stays interpretable, then evaluate it with both error metrics and graphical validation.

  • P14 tends to be the noisiest timepoint, so I downweighted it slightly during fitting

What the results suggest

  • The model captures the broad shift from stem-cell-rich to ependymal-cell-rich compartments.
  • Fit is compartment dependent rather than uniform.
  • Some compartments are predicted well, while others show larger residuals and wider uncertainty.
  • This suggests that the ventricular wall does not follow one single developmental rule.

Problems and limitations

  • The model does not explicitly account for measurement error, migration, or cell death.
  • Ependymal cells are not given their own proliferative dynamics.
  • The hardest compartments likely need stronger regularization or a more flexible temporal structure.
  • P14 remains the noisiest intermediate stage.

I would frame this as: these are the current limitations of the model, not reasons the project failed. They also explain why some compartments are much harder than others.
